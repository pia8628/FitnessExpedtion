## Context

- 目前 UI 以資訊呈現為主，缺乏一致主題，表格欄位較冗長，降低可讀性。
- 本次目標是以「冒險手帳」風格提升體驗，並統一用語（週 → 回合）。
- 需要在不改動資料來源的前提下，優先調整 UI 呈現與視覺語言。
- 使用少量圖片，先導入「地圖圖卡」作為主要視覺素材。

## Goals / Non-Goals

**Goals:**
- 建立一致的冒險手帳視覺系統（字體、配色、卡片、背景質感）。
- 亮橘與珊瑚紅作為強調色，其他使用柔和暖色，符合女性玩家族群。
- 地圖圖卡優先導入，作為頁面重點視覺。
- 表格/列表欄位精簡，只保留玩家需要閱讀或操作的資訊。
- 文案統一：介面內「週」改為「回合」。

**Non-Goals:**
- 不變更資料表結構與資料來源。
- 暫不加入怪物卡與事件卡圖片。
- 不新增新的遊戲功能或規則。

## Decisions

1. **視覺主題：冒險手帳**
   - 理由：手帳感更貼近「冒險紀錄」與女性玩家偏好，能自然承載卡片、貼紙、標籤等元素。
   - 替代方案：復古RPG/科技控制台。因與目標族群偏好不符而不採用。

2. **字體組合**
   - 標題：`Playfair Display`（或 `Cormorant Garamond` 作備選）
   - 內文：`Noto Sans TC`（或 `Source Han Sans TC` 作備選）
   - 理由：標題有故事感、內文字體清晰易讀，且雙語混排穩定。

3. **配色系統**
   - 強調色：亮橘、珊瑚紅（CTA、重點標籤、狀態徽章）
   - 背景色：柔和米色、暖灰、淡粉膚色
   - 理由：整體溫暖、低對比，減少疲勞，符合女性玩家審美。

4. **卡片化與表格精簡**
   - 改以卡片/分區呈現任務、狀態、事件重點。
   - 表格僅保留玩家關注欄位（例如：名稱、狀態、期限、獎勵），移除內部識別或冗餘欄位。
   - 理由：提升掃讀效率、降低資訊噪音。

5. **地圖圖卡導入**
   - 先增加一張地圖圖卡作為主視覺（其餘怪物/事件卡暫緩）。
   - 樣式偏手繪或簡約插畫，搭配紙張質感底。
   - 理由：有明確視覺焦點且風險低。

## Risks / Trade-offs

- **[字體載入/相容性]** → 使用可回退的字體堆疊，避免載入失敗。
- **[圖片資產品質不一致]** → 規範尺寸與色調，避免風格落差。
- **[表格精簡造成資訊不足]** → 僅移除非玩家操作所需欄位，保留關鍵資訊。
- **[過度裝飾影響可讀性]** → 以留白與層級為主，裝飾元素限量使用。
